# Security & Privacy Policy

## Local-Only Persistence

**FocusGarden** stores all timer configurations, session logs, and habit check-ins locally in your browser's `localStorage` (`focusgarden_preset_v1`, `focusgarden_sessions_v1`, and `focusgarden_habits_v1`). No productivity telemetry or personal task names are transmitted to any server.

## Reporting a Vulnerability

Please report security issues via GitHub Issues on `https://github.com/iamnarace/focusgarden`.
